# 网站设计调研笔记（2026-11-26）

做网站之前，按用户的要求查了 GitHub 上能让页面更美观的现成资源：提示词、Claude skill、模板、组件库、数据可视化规范。下面是挑出来真正有用的三个，以及看过但没采用的。

**安全口径**：查到的 skill 和提示词只当参考资料读，没有执行里面的任何命令或安装脚本，也没有照它们的话访问网址、改配置。网站最后没有引入任何第三方代码，所以页面里没有需要随附的第三方许可证文本；参考过的资料在页脚和 README 里注明出处。

---

## 1. Anthropic 官方 skill：frontend-design

- **是什么**：Anthropic 公开的 Claude skill，教模型做“不像 AI 套模板”的前端页面。内容是设计原则和一份“常见套路清单”，不是代码。
- **链接**：<https://github.com/anthropics/skills/tree/main/skills/frontend-design>（SKILL.md 和 LICENSE.txt 都直接读过原文）
- **许可证**：Apache License 2.0（`skills/frontend-design/LICENSE.txt`）。
- **怎么用**：只借它的原则，不复制文字。具体落到本站的几条：
  - **先想清楚对象**：读者是做数字验证的工程师，他们每天看的东西是波形查看器。所以首页开头放一段**真实的波形**（PicoRV32 前几百个周期，从 `sample/` 里取），旁边是**同一批比特排成的视频帧**。这一张图就把“把波形当视频存”这个想法讲明白了，是全站唯一允许“抢眼”的元素，其余部分保持安静。
  - **字体**：只用一套系统无衬线字体加一套等宽字体（信号名、命令行用），字号分级明确；正文每行不超过约 70 个字符宽。
  - **避开它点名的套路**：不用一排一模一样的圆角卡片加阴影；不用每节都淡入上滑的动画；不用奶油底加赤陶色、黑底加荧光绿这类俗套配色；不在每个链接后面加箭头。
  - **底线**：手机上能看、键盘焦点可见、尊重“减少动态效果”、对比度够。

## 2. Claude Code 自带的 dataviz skill（数据可视化方法加配色校验脚本）

- **是什么**：一套做图表的步骤和规范：先选图形再配色；分类色按固定顺序用；色盲安全要**算**出来而不是凭眼睛；线宽、点大小、悬停提示、表格视图都有具体规格。附带一个可以运行的配色校验脚本 `validate_palette.js`。
- **来源**：随 Claude Code 一起分发的内置 skill，**不在 GitHub 上**。在这里列出，是因为它对本站图表的帮助最直接。许可证文本没有随 skill 一起提供，所以只用它的方法和公开的色值，不复制脚本进仓库。
- **怎么用**：
  - 主图是散点图（体积对读取耗时）。按规范，散点图的所有点两两都可能相邻，最多只能用**前三个分类色**。所以颜色只分三族：**视频**、**数据表**、**打包矩阵**；FST 和 VCD 这些对照组用中性墨色，形状再区分一次，不只靠颜色。
  - 实际运行了校验脚本（`node validate_palette.js ... --pairs all`）：浅色 `#2a78d6,#eb6834,#1baf7a` 全部通过，色盲最差色差 9.2，正常视觉最差 24.0；绿色那一个在浅色底上对比度只有 2.74，规范要求这时必须有可见标签或表格视图，所以每张图都配了表格视图。深色 `#3987e5,#d95926,#199e70` 全部通过。
  - 细线细点、2px 表面色描边、悬停区域比点大、图例总是有、文字不用数据色、深色模式单独选色而不是自动反色。

## 3. Observable Plot（看过，最后没用）

- **是什么**：Observable 出的 JavaScript 图表库，语法简洁，对数坐标、悬停提示都是现成的。
- **链接**：<https://github.com/observablehq/plot>，最新版本号 v0.6.19（从 Releases 页读到）。
- **许可证**：ISC（`LICENSE`，“Copyright 2020-2025 Observable, Inc.”）。
- **为什么没用**：本站只有两三种图，而且要求能**离线本地打开**。用它要么每次从 CDN 拉（离线打不开），要么把它和 d3 的打包文件下载进仓库。两种都不划算，所以图表用不到 400 行原生 JavaScript 加 SVG 手写。它的文档里“tip”（悬停提示）和对数坐标的设计被拿来参考。

## 看过但没采用

- **UrbanInstitute/graphics-styleguide**（<https://github.com/UrbanInstitute/graphics-styleguide>）：一家智库的图表规范。仓库里 LICENSE 文件写 Apache-2.0，README 却写代码按 GPL-3.0 发布，两处矛盾；而且主要是 Excel 模板。所以没用。
- **配色集合**：Okabe-Ito、Paul Tol 等色盲安全配色。dataviz skill 的配色已经校验过，就没有再引入第二套。

## 本站的设计决定（摘要）

| 项 | 决定 | 理由 |
|---|---|---|
| 技术 | 纯静态 HTML/CSS/JS，无构建步骤，无第三方库 | 离线可开；以后公开也只是拷文件 |
| 数据 | `web/build_data.py` 从 `results/` 的 CSV 生成 `web/data/bench.js` | 页面数字不手抄 |
| 语言 | 只用英文（页面文字、图表标签、说明页） | 用户 2026-11-26 改的要求（最初是中英双语，已去掉中文版和语言切换） |
| 版式 | 单列阅读宽度，图表区放宽；窄屏下图表全宽、表格可横向滚动 | 手机能看 |
| 主题 | 跟随系统浅色/深色，深色单独选色 | dataviz 规范 |
| 主图 | 散点：横轴体积（相对 FST 默认档），纵轴读取耗时（相对 libfst），两轴对数，可切换波形和读法，悬停看数字，可切到表格 | 一张图同时回答“小不小”和“快不快” |
| 副图 | 点图：关键格式在五个波形上的体积倍数 | 看规模和活动度的影响 |
